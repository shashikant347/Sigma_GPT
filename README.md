# 🤖 Sigma GPT

Sigma GPT is an AI-powered chat application built with a modern **MERN-style architecture**. It provides a simple and responsive interface where users can interact with an AI model and receive real-time responses.

## 🚀 Tech Stack

### Frontend

* React.js
* JavaScript
* CSS
* Axios

### Backend

* Node.js
* Express.js
* REST API
* Groq API

## ✨ Features

* 💬 AI-powered chat interface
* ⚡ Fast API responses
* 🔐 Backend API integration
* 📱 Responsive React frontend
* 🧩 Separate frontend and backend architecture
* 🔄 Real-time conversation flow

## 📁 Project Structure

```text
Sigma-GPT/
├── frontend/     # React.js frontend
└── backend/      # Node.js + Express.js backend
```

## 🛠️ How It Works

The **React frontend** provides the user interface for chatting with the AI.

The **Node.js + Express.js backend** handles API requests and communicates with the AI service. The backend then sends the generated response back to the React frontend.

## 🎯 Purpose

This project was built to practice and demonstrate **React.js, Node.js, Express.js, REST APIs, and AI API integration** while building a real-world AI chat application.
